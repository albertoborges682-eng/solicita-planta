========================================
ABRIR PASTA DO PROJETO NO POWERSHELL
========================================

cd C:\projeto-mobile\solicitaplanta-app


========================================
ABRIR PROJETO NO VS CODE
========================================

code .


========================================
RODAR EXPO (FRONTEND)
========================================

npx expo start


========================================
ENTRAR NO BACKEND
========================================

cd backend


========================================
CRIAR AMBIENTE VIRTUAL
========================================

python -m venv venv


========================================
ATIVAR VENV
========================================

.\venv\Scripts\activate


========================================
DESATIVAR VENV
========================================

deactivate


========================================
INSTALAR DEPENDÊNCIAS BACKEND
========================================

pip install fastapi uvicorn sqlalchemy


========================================
RODAR FASTAPI
========================================

uvicorn main:app --reload --host 0.0.0.0
